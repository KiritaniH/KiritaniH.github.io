#### Phase 3

初步对比分析如下：

| Strategy         | 优点                           | 幻觉类型                |
| ---------------- | ---------------------------- | ------------------- |
| Zero-shot T0     | 稳定                           | 数据前后对应有误，缺少必要的逻辑推理  |
| Zero-shot T1     | 思路发散，比较灵活                    | 前后必要性假设有出入，部分数据来源缺失 |
| CoT              | 推理清晰直观                       | 忽视了部分技术瓶颈           |
| Prompt Iteration | 每一步逻辑论证更加详细具体，能提出一些基于现实的修改方案 | 修改了部分已有要求，部分假设过于理想化 |
| Reasoning model  | 逻辑强                          | 部分计算和估算有误           |
| Deep Research    | 最为详细，部分缺失数据并没有编造，技术报告清晰      | 部分数据来源并非可靠          |

几个比较明显的幻觉现象如下：

- LLM提及火星的通讯延迟是4-24分钟，但实际上根据百度结果应该是4-20分钟

- 

- 根据百度百科，放射性同位素热电机提供的电力功率极低，通常低于百瓦，LLM希望用它来提供高于1kW的电力不太现实

- 在Zero-shot部分，LLM认为使用太阳能发电是可行方案，但在CoT部分又推翻了这一结论。这里我比较支持CoT的结论，因为根据这几个模型的输出，可以看到太阳能发电需要极其理想的情况，而在火星恶劣环境条件下几乎没有可行性。

- 计算供电系统设计的时候，LLM假设了一些缺少实际数据的条件来进行计算，这样的出的结果可信度不高

- Deep Research部分中有的数据来源是社区讨论，这个数据来源也很不可靠

整体而言，我认为这几个输出结果各自在不同的方面均有明显问题，可行性最高的应该是Deep Research的结果
