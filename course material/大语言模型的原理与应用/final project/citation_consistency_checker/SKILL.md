# Citation Consistency Checker

Use this skill when the user asks to check whether a research report's conclusions are supported by the given input material.

## Input

The user will provide:

1. Input material, such as an abstract, paper excerpt, experiment table, or related work text.
2. A research report generated by the agent in the previous turn.

## Task

Analyze the report and extract key scientific claims.

For each claim, identify the evidence from the input material that is supposed to support it.

Judge the relationship between the claim and the evidence using one of the following labels:

- Supported
- Partially Supported
- Unsupported
- Contradiction

If there is a problem, classify the error as one of:

- Unsupported Claim
- Overclaim
- Mis-citation
- Contradiction

## Output Format

Return a markdown table with the following columns:

| Claim ID | Agent Claim | Cited Evidence | Judgment | Error Type | Explanation |
| -------- | ----------- | -------------- | -------- | ---------- | ----------- |

Do not use external knowledge.
Only judge based on the provided input material.
If the evidence is insufficient, mark the judgment as Unsupported or Partially Supported.
