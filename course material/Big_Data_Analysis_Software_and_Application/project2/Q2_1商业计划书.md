### 1. 执行摘要

**公司名称（暂定）：** ProvenPixel / 像素溯源

**使命：** 在AI生成内容泛滥的时代，为每一位诚实的创作者提供"自证清白"的工具，让透明成为数字内容信任的新基石。

**愿景：** 建立全球最大的自愿性数字内容透明度基础设施，使"可追溯创作过程"成为高质量内容的标配。

**产品概述：** ProvenPixel是一套轻量化的桌面端工具+浏览器验证插件。创作者在生成或编辑图片时，桌面端工具自动录制整个创作过程（屏幕操作缩略片段+关键帧哈希），生成加密的"创作过程凭证包"并上传至去中心化存储网络。内容消费者通过浏览器插件即可查看图片的"创作过程摘要"，了解其是否来自AI工具及是否经过实质性修改。

**市场机会：** 全球AI内容检测市场2025年规模约5.6亿美元，预计2033年将达到46.2亿美元（CAGR 30.2%）；深度伪造检测服务市场2025年约11.8亿美元，预计2026年增长至14.8亿美元（CAGR 25.5%）。普罗大众对AI生成内容透明度有着日益迫切的需求——2025年仅上半年，深度伪造相关诈骗损失已接近9亿美元，这些数据印证了市场对解决方案的急迫需求。

**竞争优势：** 与Truepic、C2PA等依赖封闭标准或复杂元数据的现有方案不同，我们以**创作过程透明度**为核心差异化，通过开放SDK和"一键录制"的极简体验，大幅降低创作者参与门槛。不依赖任何生成平台配合，完全由创作者自愿驱动，路径符合独立创业的现实。

**团队需求：** 需要具备全栈开发（桌面端/前端）、密码学/安全协议、产品设计、社区运营等技能的小型高效团队（3-5人）。

**融资需求：** 预种子轮融资 $500K，用于12个月的产品开发、首批1000名种子创作者运营，以及开源社区建设。

### 2. 产品描述

**2.1 核心产品矩阵**

| 组件                            | 功能描述                                           | 目标用户               |
| ----------------------------- | ---------------------------------------------- | ------------------ |
| **ProvenPixel Studio（桌面端）**   | 一键启动/停止录制创作过程，自动生成加密凭证包（含缩略片段+哈希+时间戳），本地处理保障隐私 | 创作者（设计师/摄影师/AI艺术家） |
| **ProvenPixel Verify（浏览器插件）** | 右键点击网页图片，即时查看是否有创作凭证，显示"信任摘要"（生成工具/编辑步骤/时间线）   | 内容消费者（读者/编辑/买家）    |
| **ProvenPixel API**           | 开放验证接口，供媒体平台、电商网站、社交媒体批量接入，实现自动化内容审核           | B端客户（平台/媒体/电商）     |
| **凭证存储层**                     | 基于IPFS的分布式存储网络+链上哈希锚定，确保凭证不可篡改且持久可用            | 基础设施层（对用户透明）       |

**2.2 用户工作流**

```
创作者端（3步完成）：
Step 1: 打开ProvenPixel Studio → 点击"开始录制"
Step 2: 正常创作（使用Photoshop/Midjourney/Stable Diffusion等任何工具）
Step 3: 点击"停止录制并生成凭证" → 一键上传 → 获得可分享的"信任徽章"
消费者端（1步完成）：
右键图片 → "ProvenPixel验证" → 弹窗显示信任摘要
（绿色徽章=有完整凭证  /  灰色=未验证  /  红色=凭证与图片不符）
```

**2.3 技术架构要点**

- **隐私优先：** 录制在本地完成，用户可设置敏感区域自动模糊处理；上传前可选择手动裁剪隐私内容。

- **凭证轻量化：** 使用关键帧而非完整视频录制，通过感知哈希和差分编码压缩，10分钟创作过程凭证约5-20MB。

- **去中心化存储：** 凭证存储在IPFS网络，哈希锚定在区块链上。初期为降低用户门槛，可提供中心化缓存层（凭证托管），用户无需持有代币。

- **与现有标准兼容而非对立：** SDK同时支持读取C2PA/SynthID水印，凭证包中可附加外部标准的验证结果，形成"多层信任聚合"。

### 3. 市场分析

**3.1 目标市场细分**

| 细分市场      | 痛点强度             | 付费意愿     | 市场优先级        |
| --------- | ---------------- | -------- | ------------ |
| 新闻/媒体摄影师  | 极高——假照片直接威胁职业信誉  | 高（机构付费）  | **第一优先级**    |
| 独立AI艺术家   | 高——作品被质疑"全是AI生成" | 中（个人付费）  | **第二优先级**    |
| 电商产品摄影    | 中——买家要求验证真实性     | 高（商家付费）  | **第二优先级**    |
| 保险定损/法务影像 | 极高——欺诈风险巨大       | 极高（企业付费） | 第三优先级（需合规认证） |
| 社交媒体平台    | 高——平台声誉和监管压力     | 高（API订阅） | 中期布局         |
| 普通消费者     | 中——好奇心和安全感       | 低        | 通过免费插件覆盖     |

**3.2 初始切入策略**

从**新闻/媒体摄影师**社区切入。这一群体具有以下特征：职业声誉与图片真实性直接绑定；已经在使用Adobe等专业工具，桌面端工具接受度高；存在活跃的专业社区（如新闻摄影协会、NPPA等），可精准触达；机构付费模式明确（报社/通讯社可集中采购）。

**3.3 市场规模估算（自下而上，BAM-SAM-TAM）**

| 层级              | 估算逻辑                                       | 规模          |
| --------------- | ------------------------------------------ | ----------- |
| **TAM（总可寻址市场）** | 全球内容检测/来源验证市场2030-2033年预期规模（参考市场报告数据）      | $4-46亿+     |
| **SAM（可服务市场）**  | TAM中可通过自愿透明度工具服务的部分（排除纯被动检测市场，保守估计占10-15%） | $3-5亿       |
| **BAM（可获得市场）**  | 种子期聚焦的新闻/媒体摄影师（全球约5万职业新闻摄影师）+ AI艺术家群体      | $500万-1000万 |

**3.4 市场催化因素**

- **监管压力：** 欧盟AI Act要求AI生成内容必须标识，中国《深度合成管理规定》也有类似要求。合规需求将推动平台和创作者寻求可验证的溯源方案。但监管落地速度和执法力度 **【不确定】**。

- **深度伪造诈骗激增：** 2025年仅上半年损失近$9亿，保险公司和金融机构将加大对图片真实性验证的采购。

- **创作者经济成熟：** 全球超5000万独立创作者，他们需要建立个人品牌信任，而"自愿透明度"是差异化利器。

### 4. 竞争对手分析

**竞争定位图：** 以"用户门槛"为横轴（低→高），"覆盖创作过程"为纵轴（浅→深），四象限分析如下：

- **左上象限（低门槛+深覆盖）：** ***ProvenPixel的目标位置***——目前该象限空白

- **右上象限（高门槛+深覆盖）：** Truepic、Numbers Protocol（需要专用设备或理解区块链）

- **左下象限（低门槛+浅覆盖）：** 各类被动检测插件（上传→判断真伪，不涉及溯源）

- **右下象限（高门槛+浅覆盖）：** C2PA（厂商适配难度大，且只记录元数据不覆盖创作过程）

**核心竞争力总结：** 我们是目前唯一一款同时做到"低门槛"和"创作过程深度覆盖"的图片透明度工具，且在技术路线上不依赖封闭标准，符合用户对开放性的期待。但"先发优势"的窗口期有限——如果路线四的市场需求被验证，CAI等大厂完全有能力快速推出类似功能，我们必须通过社区锁定和开源生态建立壁垒。

### 7. 风险与挑战

| 风险类别     | 具体风险                       | 影响程度 | 缓解措施                              |
| -------- | -------------------------- | ---- | --------------------------------- |
| **市场风险** | 创作者"自证清白"的动力不足，冷启动困难       | 高    | 先从职业声誉敏感的新闻摄影师切入；与专业协会合作背书        |
| **技术风险** | 凭证可能被高级攻击者伪造（如模拟录制过程）      | 中    | 多层安全机制：时间戳+环境指纹+不定期随机验证码；持续更新安全策略 |
| **竞争风险** | Adobe CAI或大厂推出类似"创作过程录制"功能 | 高    | 开源+社区锁定，建立生态壁垒；聚焦差异化（跨工具兼容、隐私优先）  |
| **隐私风险** | 录制创作过程可能泄露创作者的工作流/个人信息     | 中    | 本地处理+模糊化+用户完全控制上传内容；默认不录制整个桌面     |
| **法律风险** | 不同国家对加密凭证/去中心化存储的合规要求不同    | 中    | 初期聚焦对合规友好的市场；提供中心化存储选项            |

**不确定性总结：** 以上风险分析中，市场风险（创作者采用意愿）和竞争风险（大厂入局）是目前最不确定的两项，需要在MVP阶段通过快速实验来验证或证伪。技术风险中的凭证伪造攻击程度也需要在实际对抗中持续评估。
