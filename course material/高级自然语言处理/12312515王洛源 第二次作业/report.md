- **任务复杂度与秩 r 相关。** 在语言模型微调时，参数变化并不是随机的，而是只沿着某些语义相关的方向移动，因此LoRA能捕捉这些变化，接近完整微调的效果。

### Q2

（1）

- Greedy Search：在每一步都选择概率最高的 token，优点是实现简单且速度快，缺点是容易生成简单重复或不合逻辑的句子

- Beam Search：保留前 k 个得分最高的候选句（beam size = k），在每一步扩展它们并计算累计得分。直到生成 $<eos>$ 或到达最大长度。随后对于已有的句子，计算 normalized likelihood score 防止短句得分偏高，选择最优的句子。注意当 k=1 时，Beam Search会退化为Greedy Search

- Top-K Sampling：固定一个整数 K，每一步只保留概率最高的 K 个 token，其余全设为 0 并重新归一化，然后从新的 p′ 中随机采样一个 token

- Top-P Sampling：固定一个概率阈值 P ，随后每步选择最小的 token 集合 S，使得这些token的概率之和大于等于给定的P，然后将这些选中的token概率归一化并随机选择

（2）

- Temperature：控制输出的可预测性。较低的温度使得输出结果更稳定，使模型专注于最可能产生的结果；较高的温度使得模型能在更大的范围内探索输出结果，更具创造性

- k ：控制Top-K算法的保留 token 数。较高的 k 值能使候选的 token 增多，生成的句子更多样，也更容易出错；较低的k值使得输出更稳定保守，也更单调

- p：与 k 类似，控制Top-P算法的概率阈值，较高的 p 值与较低的 p 值和 k 值的结果对应类似

- p_min：控制筛选概率较低 token 的阈值，较高的 p_min 值与较低的 k 值效果类似，反之亦然
