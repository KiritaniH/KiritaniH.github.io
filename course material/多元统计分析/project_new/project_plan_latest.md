# MA304 Project 2 最新执行方案

## 题目

证券投资策略与客户交易画像精准匹配研究

## 1. 项目目标

本项目围绕“客户交易画像与量化策略精准匹配”展开。核心目标不是单纯做聚类或推荐，而是构建一套可解释、可复现、可继续扩展的数据分析流程，用于回答以下问题：

1. 不同量化策略在交易行为、持仓结构和风险收益特征上是否存在稳定差异。
2. 不同客户是否能通过交易数据提取出具有业务含义的风格画像。
3. 是否可以先用“投资风格相似度”筛选候选策略，再用“收益风险表现优于客户”这一条件完成推荐。
4. 在当前样本有限的前提下，模拟客户数据能否帮助建立一个初步可行的方法框架。

## 4. 特征体系设计

为了落实修改意见并提升解释性，最终特征体系采用 3 组共 18 个特征，其中前 12 个用于风格匹配，后 6 个用于收益风险优选。

### 4.1 交易行为特征（4 个）

1. `log_trade_freq`
2. `avg_hold_days`
3. `turnover_rate`
4. `log_avg_trade_amount`

### 4.2 持仓结构特征（8 个）

1. `buy_sell_ratio`
2. `trade_regularity`
3. `num_stocks`
4. `concentration_top3`
5. `concentration_top1`
6. `avg_position_pct`
7. `position_peak_ratio`
8. `stock_turnover`

说明：

- `position_peak_ratio = max_position_pct / avg_position_pct`
- 该构造用于替代单纯同时保留 `avg_position_pct` 与 `max_position_pct` 所导致的冗余问题

### 4.3 风险收益特征（6 个）

1. `avg_return_pct`
2. `win_rate`
3. `profit_loss_ratio`
4. `max_drawdown`
5. `return_volatility`
6. `sharpe_approx`

## 5. 特征提取原则

### 5.1 策略数据

策略数据来自量化策略交易流水。以交易记录为基础：

- 识别买入与卖出行为
- 重建逐笔现金流与近似持仓变化
- 计算交易频率、持仓集中度、仓位变化等风格特征
- 以配对交易近似计算单笔收益
- 以累计净值序列近似计算回撤与波动

### 5.2 客户数据

客户数据仅有交易记录，缺少完整日度资产快照，因此采用“可解释近似重建”：

- 用买卖方向、成交额、交易日期和个股代码重建交易风格
- 用 FIFO 配对方式估计单笔实现收益
- 用累积实现盈亏构造近似权益曲线
- 风险收益特征统一在同一口径下计算，保证与策略端可比较

### 5.3 模拟客户

模拟客户不直接伪造结果，而是基于真实客户特征统计规律和业务先验生成：

- 以真实客户的均值与协方差为基础
- 针对不同画像加入方向性偏移
- 对各变量进行边界约束
- 对高相关变量执行逻辑一致性修正

## 6. 分析方法

### 6.1 探索性分析

- 描述性统计
- 相关矩阵
- 异常值与尺度检查

### 6.2 降维分析

- PCA：用于解释主要风格维度并做二维可视化

### 6.3 聚类分析

为了提高稳健性，采用多方法比较：

- K-means
- 层次聚类（Ward）
- 高斯混合模型（GMM）

并用以下指标对比：

- Silhouette score
- Davies-Bouldin index
- Calinski-Harabasz score
- ARI（一致性比较）

### 6.4 判别分析

- 基于聚类标签做 LDA 判别投影
- 评估各簇在判别空间的分离程度
- 输出关键判别方向的解释

### 6.5 客户-策略匹配

采用两阶段机制：

#### 第一阶段：风格筛选

对前 12 个风格特征按两组计算余弦相似度：

- 交易行为组
- 持仓结构组

再进行加权：

`style_score = 0.45 * behavior_cos + 0.55 * holding_cos`

#### 第二阶段：收益优选

对风格相近的候选策略，比较风险收益特征：

- 若策略收益水平高于客户且回撤不显著更差，则给予奖励
- 若策略收益低于客户或波动/回撤显著更差，则扣分

最终综合得分：

`final_score = 0.7 * style_score + 0.3 * performance_score`

并附加硬约束：

- 候选策略需进入风格相似度前若干名
- 收益改善幅度需为正或接近零但风险明显更优

### 6.6 统计验证

在当前样本规模与依赖包条件下，优先使用稳健且可实现的检验：

- 聚类间关键特征的 Kruskal-Wallis 检验
- 相关性与效应量分析
- 匹配前后风格距离对比

如后续补齐更多样本，可扩展到 MANOVA、Hotelling T²、CCA。

## 8. 研究判断标准

如果出现以下情况，则认为结果足以形成“初步结论”：

1. 聚类结果在不同方法间具有中等以上一致性。
2. 真实客户的推荐结果与业务直觉基本一致。
3. 推荐策略在风险收益维度上相对客户具有可解释优势。
4. 关键图表和统计检验支持“风格存在差异、匹配具有一定合理性”的判断。

如果上述条件未满足，则继续调整：

- 特征缩放方式
- 匹配权重
- 模拟客户分布
- 候选策略筛选阈值
